03 / RAGDual-Model RAG PipelineRead project PDF ↗

Dual-Model Retrieval-Augmented Generation (RAG) Pipeline

Local museum-data chatbot that uses DeepSeek-R1 and Llama 3.2 to answer natural-language questions and resolve conflicting summaries.

Architecture & guardrails

Ollama orchestrates both local models. A query engine generates executable Python Pandas code from natural-language questions, strips Markdown from generated code with a regex cleaner, and handles references to unavailable fields without crashing.

A Llama 3.2 “Judge” checks model summaries against the raw museum data, resolves factual disagreements, and produces one unified response. A 10-row guard asks for query refinement when more than ten artifacts match.

05 / CLOUDScalable Image ProcessingRead project PDF ↗
AWS LAMBDA · S3 · CLOUDWATCH · PYTHON 3.9

Scalable Serverless Image Processing Pipeline

Built an event-driven AWS workflow that converts uploaded images to grayscale and measures Lambda scaling under a 150-image burst.

Architecture & performance

S3 object-created notifications trigger a Python 3.9 Lambda function. Pillow (PIL), packaged in a Lambda Layer, converts each image to grayscale before saving it in an output bucket; Boto3 connects the workflow to AWS services.

Least-privilege IAM roles permit only the required S3 read/write and CloudWatch logging access. A multithreaded CloudShell load script submitted 150 images; CloudWatch recorded scale-out to 36 concurrent Lambda environments, followed by scale-in to zero after processing.

The default 3,000 ms timeout correlated with a 33% error rate. Proposed production tuning: raise memory from 128 MB to 512 MB and extend the timeout to 10 seconds.
